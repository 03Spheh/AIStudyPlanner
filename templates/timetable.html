Personalized Study Timetable

Tell the planner when you are available to study. The system will then decide which modules should be studied during those periods.

Important: You do not choose which module goes into each time slot. The intelligent scheduling algorithm makes that decision using assessment dates, credits, assessment type, study gaps and study spacing.

1. Your Weekly Availability

Choose your own available time for each day. You can leave a day unavailable if you are busy. Overnight sessions such as 22:00 → 04:00 are supported automatically.

2. Study Preferences

Breaks are optional. When enabled, the planner places a 15-minute break between study sessions.

3. Your Modules

Enter your academic information. The planner uses this information to decide which module should receive attention.

4. How the Planner Makes Decisions

📅 Due-Date Urgency

Assessments that are closer receive a higher scheduling priority.

🎓 Credit Weight

Modules with more credits can receive greater attention, but credits are not the only factor.

📝 Assessment Type

Exams and tests receive different priority weights from assignments and practical work.

⏳ Study Gap

If a module has not been studied for several days, its priority increases.

🔄 Study Spacing

The planner tries to avoid repeatedly scheduling the same module when other modules need attention.

📚 Two-Module Rule

A single day will contain a maximum of two different modules.
